# PriorAuth AI - Frontend

Healthcare SaaS platform for prior authorization triage and policy companion.

## Tech Stack

- React 18 + TypeScript
- Vite
- React Router v6
- TanStack Query (API data)
- Zustand (UI state)
- Tailwind CSS
- Recharts
- Lucide Icons

## Getting Started

\`\`\`bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
\`\`\`

## Project Structure

- `src/components/` - Reusable UI components
- `src/pages/` - Route pages
- `src/lib/` - API client, utilities
- `src/store/` - Zustand stores
- `src/hooks/` - Custom React hooks
- `src/types/` - TypeScript types

## Design System

Follows the PriorAuth AI design system:
- Primary Blue: #2563eb
- Success Green: #16a34a
- Alert Red: #dc2626
- Pending Amber: #f59e0b
- Compact, information-dense UI
- Inter font family
- Dark mode support
